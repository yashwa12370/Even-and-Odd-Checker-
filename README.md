🔢 Even & Odd Checker

A simple, interactive Even & Odd Checker built with HTML, CSS, and JavaScript.

✨ Features

- 🔢 Instant Even/Odd checking
- 📊 Total, Even & Odd statistics
- 📜 Recent checks history
- 🗑️ Clear history
- 🎲 Random number generator
- 🌙 Dark/Light mode
- 💾 Local Storage
- 📱 Responsive design
- ✨ Modern glassmorphism UI

🛠️ Technologies

- HTML5
- CSS3
- JavaScript

🚀 How to Run

Open "index.html" in your browser.

No external libraries required.

👩‍💻 Project

Built to practice JavaScript logic, DOM manipulation, Local Storage, and responsive UI design.
